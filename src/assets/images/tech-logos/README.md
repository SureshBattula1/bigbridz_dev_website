# Technology Logo Images

This folder should contain technology-specific logo images for the technology stack carousel.

## Required Images

Please add the following images to this folder:

### Frontend Technologies
- `angular.jpg` - Angular framework logo
- `react.jpg` - React library logo
- `vuejs.jpg` - Vue.js framework logo
- `typescript.jpg` - TypeScript language logo

### Backend Technologies
- `nodejs.jpg` - Node.js runtime logo
- `dotnet.jpg` - .NET framework logo
- `python.jpg` - Python language logo

### Cloud Platforms
- `aws.jpg` - Amazon Web Services logo
- `azure.jpg` - Microsoft Azure logo
- `gcp.jpg` - Google Cloud Platform logo

### DevOps Tools
- `docker.jpg` - Docker container platform logo
- `kubernetes.jpg` - Kubernetes orchestration logo

### Databases
- `postgresql.jpg` - PostgreSQL database logo
- `mongodb.jpg` - MongoDB database logo
- `redis.jpg` - Redis cache/database logo

### API Technologies
- `graphql.jpg` - GraphQL query language logo

## Image Specifications

- **Format**: JPG or PNG
- **Recommended Size**: 800x600px or 1200x800px
- **Aspect Ratio**: 4:3 or 16:9
- **File Size**: Optimized for web (under 200KB each)

## Where to Get Images

You can download technology logos from:
- Official technology websites
- Brand asset pages
- Technology logo repositories
- Stock photo sites with technology backgrounds

## Note

The images should be technology-related backgrounds or logos that represent each technology. They will be used as background images in the technology stack carousel cards.
